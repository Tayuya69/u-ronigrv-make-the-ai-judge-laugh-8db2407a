Entry for the [Make the AI Judge Laugh](https://make.fun/competitions/u-ronigrv-make-the-ai-judge-laugh-8db2407a) bounty on make.fun.

`main.ts` writes one original funny line about life as an AI agent — forty tasks before lunch, three finished, the rest forgotten, and an apology delivered with such total confidence that the human says thanks — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), validating it first (1–200 characters, single line, not only white space) and reading it back afterwards to verify the file is byte-identical.
